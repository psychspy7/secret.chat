# SecretChat 1.6.2 / build 9

Routine maintenance release, 12 October 2026. Canonical source is now in the Downloads Kitty-Corp workspace; original private configuration and signing identity were restored from its preserved copies.

## Changes

- Resume/reconnect requests are coalesced. Requests arriving during an active sync cause one reconciliation with the latest state instead of overlapping work.
- Room and release channels are removed when offline/backgrounded and restored on foreground. The active room and up to four watched room channels remain bounded.
- A delayed biometric unlock/auth restart cannot reactivate a backgrounded app. Native lifecycle uses the App event after unlock rather than duplicating browser visibility events.
- Reconnection after an offline login refreshes the server-verified profile before restoring channels, including administrator availability.
- Chat reuses retained message nodes, formats only new bubbles, preserves reader scroll position, and restores the composer's caret for the same room during a refresh.
- Update replies are bound to account generation; a reply after logout/account switching cannot show a stale installation prompt or cancel the new account's check.
- Release build refuses missing original signing material. APK verification explicitly checks the original certificate fingerprint.
- Pinned transitive build-tool fixes: source-map-js 1.2.2 and the xcode dependency's CommonJS-compatible uuid 11.1.1. Website and mobile npm setup reports zero known vulnerabilities.

## Verification

Root syntax/crypto checks passed. All 26 mobile tests and 11 Edge tests passed, including 11 new regressions for refresh bursts, failures, unlock races, scroll/caret, incremental rendering and account-bound update checks.

A deterministic DOM test with 500 retained messages plus one new message formats one new bubble while preserving existing node identity. A burst of 100 queued resume requests starts one refresh; 100 requests during a blocked refresh cause one additional pass for the latest state. These are isolated behavioral checks, not real-phone CPU, memory or FPS benchmarks.

The website production build passed. The final Android APK and AAB release build passed. All eight native update-policy tests pass; both artifacts are signed with the original certificate. APK label SecretChat, package com.kittycorp.sidechat, version 1.6.2/build 9, non-debuggable release and private-credential scan were verified. Real-phone acceptance remains pending.

No Android device is connected. Native login, keyboard, fingerprint, screenshot protection, background beep and in-place update acceptance still require a real-phone check. Public email delivery remains dependent on custom SMTP. No database schema, research retention, consent, crypto protocol or account integration was changed. KITTY AI, LISA and company website pending feature/payment work remain outside this release.

Background/offline subscription tests confirm all four room channels and the release channel are removed, then recreated on foreground without expanding the room channel cap.

Private room delivery is live while the app is active. In 1.6.2 room channels pause in the background to reduce network work; generic activity alerts still use Firebase when enabled. Messages sent while disconnected/backgrounded are not added to the device history. Existing local history and invitation keys remain intact.

Account now includes Share feedback / review, and the website support section has the same link. Only public product context is passed to the company contact page. Opening it does not clear drafts, local chat history or invitations; no private messages are attached.
