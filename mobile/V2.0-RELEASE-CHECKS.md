# SecretChat V2.0 release checks

Verified 14 October 2026. Package version 2.0.0, Android build 11, application ID com.kittycorp.sidechat, visible label SecretChat. Android 7.0+ (minSdk24), targetSdk36. Original signing identity retained.

## Implemented and preserved

The account-based Android interface also serves the website root. Join-first home, dark/light/device themes, reduced motion, optional native haptics, pinned rooms, bounded local unread counts, room/message search, encrypted drafts, explicit invitation sharing and KITTY AI/company review shortcuts are included. Admin controls are organized into Rooms, Requests, Members, Notices and Releases. Existing authentication, room duration/extensions, biometric/PIN protection, verified-admin capture exception, updater, generic alerts and research/private boundaries remain.

Legacy anonymous browser invitations, creation and permanent host administration are preserved at /legacy, /r, /create, /SECRET, /secret and /host, including descendants. Legacy rooms keep their separate original protocol and beta-access disclosure. No backend migration, reset, live chat deletion, automatic research cleanup, new credential, billing activation or another project's source change was performed.
