# SecretChat v1.6.0 · build 7

New premium S/C logo in Android launcher, welcome, launch screen, and web headers. Join room is the primary action with Create below. The original full-size logo is only in source; installed clients use resized artwork. The supplied notification sound is unchanged.

Generic join, message and update alerts use the existing Android sound channel. Live/FCM deduplication has a bounded memory window, messages never appear in push payloads, dispatch uses bounded concurrency, and release notifications have a resumable per-device outbox. [Android notification delivery](https://firebase.google.com/docs/cloud-messaging/android/receive-messages) depends on OS permissions and device availability. [Supabase background tasks](https://supabase.com/docs/guides/functions/background-tasks) avoid holding message sends open for notification dispatch.

Private rooms remain without an admin message archive. Optional research rooms are clearly labeled, require consent before joining, and retain at most 1,000 encrypted messages until an approved manual clear. Only the verified administrator can unlock the password-encrypted research vault and view/export those rooms. Administrator clears and unanimous member votes synchronize local deletion using authenticated chat epochs; existing copies/exports and old apps cannot be erased.

Validation: 14 mobile crypto/storage/alert/export checks, 11 Edge identity and notification checks, 31 live database permission/lifetime/clearing/retention/release-outbox groups, root website checks/build, deployed endpoint auth rejection and CORS, and real FCM credential validate-only request. Eight native update-policy tests passed. APK and AAB release builds succeeded; both retain the original signing certificate. APK identity, release mode and private-credential scan passed; Android bundle validation passed.

No Android device or emulator is connected. Before broad distribution, install over v1.5 on a real phone and check fingerprint/PIN lock, Google/email callback, normal/admin screenshots, two-user consent and shared clearing, CSV share/export, join/message beeps in foreground and background, update notification tap, and installer confirmation. No on-device performance benchmark has been measured.

Public email delivery still needs custom SMTP configured directly in Supabase; Google login is available. Research rooms require the administrator to set up the vault in Control before creating them. Existing web `/SECRET` controls and Android Control use separate room systems.

The shared research archive is capped at 4,096 messages globally and 1,000 per room; new research messages pause at capacity until an approved manual clear. Private messages are never part of that archive.
